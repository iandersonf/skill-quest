# Skill Quest
- Um projeto Real para evolução de um engenheiro de software até techlead
- Mas muito além disso, consegue acompanhar, organizar e dar feedback dos seus estudos

## Sobre o projeto
- Grande parte das pessoas não sabem como estudar e até que tipo de objetivo querem chegar
- No skill quest orientamos e organizamos seu estudo para alcançar o real objetivo e te direcionar
- Transformando escolhas duvidosas em escolhas mais assertivas.

## Funcionalidades
- Criar trilhas de estudos
- Missões estruturadas (Aprendizado -> Atividade -> Feature )
- Registra progresso
- Receber orientação de pessoas que ja alcançaram seu objetivo

## Tecnologias
- Ruby
- Rails
- PostgreSQL
- Docker
- Git
- Rspec
